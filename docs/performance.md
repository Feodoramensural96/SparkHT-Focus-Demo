Step3 基准数据使用四张 640×480 合成协议图，证明真实 FP8 服务、四图顺序、结构化输出和时延，不代表机器人场景识别准确率。服务使用无思维链模板和 vLLM `response_format=json_schema`，四图输出严格保留真实 frame ID；Pydantic 继续做应用层复核。另一次 8 帧编排测试完成两批、8 个持久化结构化观察且无丢弃，证明模型客户端与会话调度闭环。

真机联调暴露出响应骨架中的 `confidence: 0.0` 会被模型逐帧照抄。聚合器没有放宽 0.55 阈值，而是把数值示例改为受 JSON Schema 约束的文字占位。修复后对安静轮保存的前后各四张真实机器人图片回放，两批分别在 9.879 秒和 9.547 秒一次完成，人物、手机、杯子字段保留 `uncertain` 语义并输出 0.85 置信度。由于这是离线回放，不冒充新的 90 秒端到端通过轮次。

启动时并行预热 ASR、Ollama 和 TTS。真机首音以 VAD 产生完整话语后到 SDK 接受首个播放块的单调时钟差计算；播放后续 Job 即使失败，也保留已经发生的首音并单独记录降级。
